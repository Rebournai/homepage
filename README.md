# Rebourn.ai — Homepage

Single-page marketing site for **Rebourn** (rebourn.ai), the AI Growth Ecosystem built by Hamed Taeb and Brett Foreman.

> "It is time to rebourn."

## About

Rebourn helps business owners adopt AI without needing a technical hire or a huge budget. This repo holds the single-page homepage site: the site's first public entry point while the fuller rebourn.ai build is in progress.

## Live site

Published via GitHub Pages from the `main` branch:

https://rebournai.github.io/homepage/

## Structure

- `index.html` — the entire site (self-contained, no build step)

## Local preview

Clone the repo and open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploying changes

Push to `main` — GitHub Pages rebuilds automatically from the root of that branch.
